# Support

This is a solo project. Help is best effort and happens in public issues.

## Get help

1. Read the repository README and its docs.
2. Search the existing issues, open and closed.
3. Still stuck? Open an issue with the form that fits:
   - Bug report: something does not work as documented.
   - Feature request: something you would like added.
   - Task: planned work.

Give the version or commit, the steps you took, and what you saw. Remove
tokens and personal data first.

## Not here

- Security problems: follow the
  [security policy](https://github.com/alawein/.github/blob/main/SECURITY.md).
- Private or paid support: not offered.
