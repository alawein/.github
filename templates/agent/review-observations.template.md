# Manual review observations

Sample: 20 consecutive eligible PRs. Record the date range, selection rule,
reviewer configuration and source links before comparing results. Fill one
row per PR manually; keep unavailable measurements `UNKNOWN`. This template
does not authorize API writes, reviewer activation or spend.

- Actionable: findings with a concrete reproducible correction.
- Accepted: actionable findings the owner accepted.
- False positive: findings disproved by linked evidence.
- Duplicate: findings repeating an already recorded correction.
- Caught pre-merge: accepted findings corrected before merge.
- Latency: actual elapsed time from review request to review availability.
- Actual cost: observed billed cost with its source, otherwise `UNKNOWN`.
- Proof: PR/review, correction and timing/cost receipts; retain overlaps.
